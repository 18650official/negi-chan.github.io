【更新说明】咪呜~我回来啦！葱酱Blog 2.0更新！

发表于2026-06-29|更新于2026-06-29
|字数总计:444|阅读时长:1分钟|阅读量:|评论数:

本次更新统一UI主题为初音绿，全面适配深色模式；优化LOGO、图标、字体及Live2D位置，修复底栏对齐与移动端显示问题；关闭分站，全部文章迁移至主站，并移除失效的MetingJS插件。


主要更新

视觉

  1. 统一了 UI 主题色为初音绿，全局适配深色模式；
  2. 更新了网站的 LOGO、背景、部分Font Awesome图标等，视觉效果统一；
  3. 修复了底栏无法对齐的问题；
  4. 优化了首页欢迎页的字体遮挡，使观感更加舒适，同时针对常见屏幕比例的移动设备进行了测试与适配；
  5. 优化了 Live2D Miku 的位置。

文章

  1. 关闭了分站 （https://trans.snowmiku-home.top），迁移了所有文章到主站点！
  2. 移除了已经失效的MetingJS Inject插件（常驻的音乐播放器）；
  3. 优化了文章图片展示 UI ，图片展示为恒定高度，解决了竖版图片显示过大的问题；
  4. 优化了内嵌 LaTex 公式的显示；
  5. 优化了文章的无障碍音频生成器。详见：https://github.com/18650official/hexo-accessble-voice-tools
  6. 对部分失效链接与图片、错别字的优化。

性能

  1. 将所有本地图片与音频托管到腾讯云 COS 服务器，优化加载速度与 GitHub 部署开销；
  2. 优化资源站上传策略与运行速度；
  3. 对移动设备的渲染进行改进，优化手机端的浏览体验。

功能

  1. 增加了“匿名提问箱”功能。

Thank you FRIENDS!!!

最后，谢谢大家一路以来的支持和鼓励，小葱也会越来越好的走下去！
